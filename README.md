# Kina — Historical Repository

> [!IMPORTANT]
> **Active KinaBot development has moved to the official
> [`usekina/kina`](https://github.com/usekina/kina) repository.** This personal
> repository is retained only to preserve the project's early provenance and
> commit history. It is no longer the source for releases, issues, security
> reports, documentation, or contributions.

Kina began as an early exploration of speech-based cognitive insights. The
current KinaBot project has since adopted clearer dignity, privacy, scientific-
claims, licensing, and responsible-use boundaries under active maintenance by
Aoi Minamoto through AImoji LLC.

For current code and project information, visit:

- [Official KinaBot repository](https://github.com/usekina/kina)
- [KinaBot website](https://www.kinabot.com/)
- [Current contribution guide](https://github.com/usekina/kina/blob/main/CONTRIBUTING.md)
- [Current security policy](https://github.com/usekina/kina/blob/main/SECURITY.md)

Historical tagline: Transforming Speech into Cognitive Insights. Detect
cognitive changes through natural conversation patterns.
